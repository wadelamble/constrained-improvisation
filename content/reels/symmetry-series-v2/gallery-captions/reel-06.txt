Symmetry to Waves · 6/27
D₃ in three dimensions

Permutations that correspond to rotations of the triangle are 120° rotations about a diagonal axis in our three-dimensional vector space. Those that correspond to flips are reflections in planes that contain the diagonal axis. The matrices do more than rearrange a list of numbers. Their action has a geometry we can draw.

Each axis in this picture records one component value. A state (a, b, c) is a point in this space, and the vector from the origin to that point is the state vector. Cycling the entries sends the point to (c, a, b). Repeating the action traces a three-point orbit around the diagonal where all three components are equal.

Every vector on that diagonal has the form (q, q, q). Permuting its entries does nothing, so the entire axis stays fixed. This is the axis about which the rotation matrix turns the rest of the space. The trace joins the starting state to the states reached by the allowed 120° turns. Only the endpoints are discrete group actions.

The flip keeps one component and exchanges the other two. If the exchanged values already agree, the state does not move. These fixed states form a plane containing the equal-components diagonal. States away from the plane are reflected across it.

Now we can notice something about these visualizations. All transformed versions of a given vector lie in one plane perpendicular to the diagonal, and these orbit planes are parallel to one another. Permuting components preserves their sum, so it also preserves their average. The position of an orbit plane along the diagonal records this common part. We can subtract it without changing the permutation structure, leaving the part on which the symmetry acts nontrivially.
