# LM Intro

Now that we know the geometry of spacetime in which motion takes place, we can ask how objects move and influence one another.

## Paths

Imagine a path between fixed points in spacetime. Could we assign a number to that path? What conditions would that number need to satisfy?

[diagram of path alternatives]

First, paths would have to belong to a set. They clearly do: we can consider the set of all possible paths between the same endpoints. Once we have such a set, we can map each member of it to a number.

For the moment, let our physical system be a single particle moving through spacetime. In that case, the path is the physics. The worldline tells us where the particle is at every time, past or future. So, between fixed endpoints, assigning numbers to paths means assigning numbers to possible histories of the system.

All observers must agree on the physics. This is the essence of physical symmetry. Different descriptions cannot change what actually happens. Everyone agrees on how pool balls move on the table, even if they use different coordinate systems. Therefore, the number associated with a path must be a spacetime invariant.

Given only a bare particle path, the natural invariant available to us is proper time, or equivalently proper path length. So our first path-number has to be proper time, up to a scale factor.

Now the question becomes: how could such numbers select the physical path?

We have a functional, \(S[\text{path}]=\text{value}\). A functional is like a function, except its input is itself a function. In this case, the input is a path.

From ordinary calculus, we know functions have special points: minima, maxima, and saddle points.

[diagram]

We also know how to find those points for ordinary functions. The problem here is that our input is not a number but an entire path. We need the analogous procedure for functionals.

If we could find the stationary path of the right functional, would that path represent the physics? This is the central wager of Lagrangian mechanics. We search for an invariant functional whose stationary paths are the physical histories.

At the level of setup, we are free to choose the input functional. The discipline is that it must be built from invariant structure. The test is whether its stationary paths match the physical ones. The action principle turns motion into constrained optimization over histories.

The worldlines that emerge from this procedure have an architectural character. Lines, geodesics, curves, waves, conserved flows, and other patterns become immediately comprehensible once the right functional has been found. These observable regularities are not decorative. They are the visible shapes taken by the theory's symmetries.
